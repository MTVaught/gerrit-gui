# Earlier vote, lines since that review, unresolved count

Fifteen alternatives, five per addition, generated by `mock.js` from a copy
of the app stylesheet (`base.css`). Each set changes one thing and leaves
the other two at a neutral baseline.

- `vote-*`: where the reviewer's vote on the patch set they last reviewed is shown.
- `delta-*`: how the lines changed since that review sit next to the whole change's counts.
- `unresolved-*`: where the unresolved comment count sits so it stops drifting with the diff numbers.

Chosen: vote 5 (a line under the request note), delta 4 (in brackets on
the same line), unresolved 3 (a comment bubble by the change number).

Regenerate: `node docs/mockups/review-delta/mock.js`, then shoot each page
with `docs/mockups/shot.cjs`.
