# Verification

The implementation keeps the immediate reply parent's original anchor for writes and uses server or parent-thread mapping for display. New draft IDs remain in their visible thread while mapping catches up. The initial composer reveal waits through large-diff layout, while respecting focus moved to another control such as Go to line. Existing saved anchors are not migrated.
